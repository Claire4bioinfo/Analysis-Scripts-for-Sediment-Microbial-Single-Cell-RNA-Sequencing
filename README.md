# Analysis-Scripts-for-Sediment-Microbial-Single-Cell-RNA-Sequencing
This repository contains the analysis scripts and associated resources used to generate the main figures and perform the downstream analyses described in the manuscript. The scripts are organized according to the corresponding figures and panels in the manuscript.

## Figure 3 — Taxonomic Composition and Abundance
### `Fig3bc-meta_sc_correlation`

Analysis of the correlation between metagenomic and microbial single-cell RNA sequencing (mscRNA-seq) taxonomic composition.

### `Fig3d-genus_abundance_stacked_bar`
Generation of stacked bar plots showing genus-level abundance across samples.

### `Fig3e-species_abundance_stacked_bar`
Generation of stacked bar plots showing species-level abundance across samples.

### `Fig3f-species_abundance_heatmap`
Generation of the species-level abundance heatmap across samples.


## Figure 4 — Cell-Level Characteristics and Taxonomic Distribution
### `Fig4a-cell_gene_counts_sample`
Analysis and visualization of the number of detected cells and genes across samples.

### `Fig4b-reconstruct_umap_manual`
Reconstruction of the UMAP visualization using the manually annotated microbial functional clusters.

### `Fig4b-Cluster_site_genus_species_circos`
Generation of Circos plots showing the relationships among functional clusters, sampling sites, genera, and species.

### `Fig4c-Sankey_L1234`
Generation of the Sankey diagram illustrating the relationships among sampling locationssites and microbial functional clusters.


## Figure 5 — Functional Heterogeneity and Within-Taxon Analysis
### `Fig5a-Marker_cog_dotplot`
Visualization of cluster marker genes and their corresponding COG functional categories.

### `Fig5a-cluster_genus_Starcked_bar`
Generation of stacked bar plots showing genus composition across manually annotated functional clusters.

### `Fig5b-umap_function`
Visualization of the UMAP embedding colored according to functional cluster annotations.

### `Fig5c-cluster_overlap_coefficient`
Calculation and visualization of the overlap coefficient between functional clusters based on their marker genes.

### `Fig5d-cluster_marker_upset`
UpSet plot showing the intersections of marker genes among functional clusters.

### `Fig5d-COG_ring_plot`
Generation of the COG functional-category ring plot based on cluster marker genes.

### `Fig5efg-within_taxon_reclustering`
Within-taxon reclustering analysis to evaluate transcriptional heterogeneity among cells belonging to the same microbial taxon.


## Figure 6 — Species-Level Functional Variation and Co-expression Networks
### `Fig6a_species_sample_gene_expr`
Analysis of gene expression patterns across species and samples.

### `Fig6b-Heatmap_markers_sample`
Generation of heatmaps showing marker-gene expression patterns across samples.

### `Fig6cde_hdWGCNA_co-expression_sample`
Construction and analysis of weighted gene co-expression networks using hdWGCNA, including module identification and sample-level module analysis.

### `Fig6f_hubgene_sample_bubble`
Visualization of hub-gene expression andor module-associated hub genes across samples using bubble plots.

# Input Data and Resources
The analyses require processed expression matrices, cell-level metadata and taxonomic annotations as appropriate for each analysis.

Important input resources include:
 Processed cell-by-gene expression matrices
 Cell-level metadata
 Taxonomic assignments at genus and species levels
 Reference genome information
 Cluster annotations
 Marker-gene tables and annotations 
 COG functional annotations
 Sample and site information
 (All annotations are generated by eggnog software, see Methods)


# Software and Analysis Framework

The analyses were performed primarily using R and commonly used R packages for single-cell analysis, visualization, clustering, network analysis, and functional annotation.

The specific parameters and settings used for each analysis are provided in the corresponding scripts.

The scripts are intended to provide a reproducible computational workflow for the analyses presented in Figures 3–6.
